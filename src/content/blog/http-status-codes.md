## 主要分类

| 状态码 | 含义 |
| --- | --- |
| 1xx | 信息响应，请求已收到，服务端要求继续 |
| 2xx | 成功，请求被正常处理 |
| 3xx | 重定向，资源位置变了或用缓存 |
| 4xx | 客户端错误，请求本身有问题 |
| 5xx | 服务端错误，服务端处理失败 |

## 常见状态码

| 状态码 | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 302 | 临时重定向 |
| 304 | 缓存未修改，用本地副本 |
| 404 | 资源不存在 |
| 500 | 服务端内部错误 |
| 401 | 未认证，token 缺失或过期 |

## 状态码汇总

### 1xx 信息响应（基本用不上）

| 状态码 | 含义 |
| --- | --- |
| 100 | 客户端可以继续发送请求体 |
| 101 | 协议升级，WebSocket 握手用 |

### 2xx 成功

| 状态码 | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 201 | 资源创建成功，POST 后返回 |
| 204 | 成功但无响应体，DELETE 常用 |
| 206 | 返回部分内容，断点续传、视频拖进度条 |

### 3xx 重定向

| 状态码 | 含义 |
| --- | --- |
| 301 | 永久重定向，会被缓存，SEO 权重转移 |
| 302 | 临时重定向 |
| 304 | 协商缓存命中，用本地副本 |
| 307/307 | 严格保持原请求方法，不会把 POST 变 GET |

### 4xx 客户端错误（核心）

| 状态码 | 含义 |
| --- | --- |
| 400 | 参数格式错误 |
| 401 | 未认证，token 缺失或过期 |
| 403 | 已认证但无权限 |
| 404 | 资源不存在 |
| 405 | 请求方法不被允许 |
| 409 | 状态冲突，重复提交、乐观锁 |
| 413 | 请求体过大 |
| 422 | 格式对但语义校验失败 |
| 429 | 触发限流 |

### 5xx 服务端错误

| 状态码 | 含义 |
| --- | --- |
| 500 | 服务端内部错误 |
| 502 | 网关拿到上游的无效响应，后端挂了 |
| 503 | 服务暂时不可用，过载或维护 |
| 504 | 网关等待上游超时 |
| 505 | 协议版本不支持 |
| 506 | 服务端内容协商配置错误 |
